# Screens

The interface as it stands, for a review that cannot open a browser.

Everything here is the built-in demo tape or a synthetic fixture generated in
the page. **No real session appears in any of them** — not a project directory,
not a session id, not a line of anybody's transcript. That is a rule rather
than a habit: `verify.mjs` refuses a home directory or anything shaped like a
session id anywhere in the tree, and a screenshot is a file in the tree.
